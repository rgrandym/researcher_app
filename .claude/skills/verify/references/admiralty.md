# Admiralty (NATO) source grading

Two independent axes. Grade both, always: `B2`, `D4`.

## Reliability of the source (A–F)

| | |
|---|---|
| **A** | Completely reliable — no doubt of authenticity; long history of accuracy. Regulators, courts, audited filings, peer-reviewed replication. |
| **B** | Usually reliable — minor doubts. Major wire services, established journals, reputable statistical agencies. |
| **C** | Fairly reliable — occasional inaccuracy. Trade press, industry analysts, well-run blogs with a track record. |
| **D** | Not usually reliable — significant doubts. Vendor marketing, advocacy groups, low-editorial outlets. |
| **E** | Unreliable — history of inaccuracy. Content farms, SEO aggregators, unattributed sites. |
| **F** | Cannot be judged — no basis for assessment. Anonymous posts, dead links, unknown provenance. |

## Credibility of the information (1–6)

| | |
|---|---|
| **1** | Confirmed by independent sources; logically consistent; agrees with other known information. |
| **2** | Probably true — not confirmed independently, but consistent with known facts. |
| **3** | Possibly true — reasonable, but not confirmed and only partly consistent. |
| **4** | Doubtful — not confirmed and contradicts some known information. |
| **5** | Improbable — contradicts known facts. |
| **6** | Cannot be judged — no basis for comparison. |

## Applying it

- **The axes are independent.** A reliable outlet reporting an unconfirmed rumour is `B3`. An anonymous leak later confirmed by filings is `F1`.
- **Independence is the whole game for the numeric axis.** Two outlets running the same press release are one source. Trace to origin before claiming confirmation.
- **A vendor citing its own metrics is `D2` at best** — reliable about itself, unaudited, self-selecting.
- **Downgrade for distance.** Each hop from primary source costs a grade: study `A1` → journal write-up `B2` → trade summary `C3` → aggregator `E4`.
- **`F6` is not "bad", it is "unknown"** — and unknown provenance never supports a load-bearing claim.

## Reporting thresholds

- Load-bearing claims (the ones the recommendation rests on): require **B2 or better**, or flag explicitly.
- Anything `D` or worse, or any `4`+: cite it only with attribution in-line ("according to <vendor>, …"), never as fact.
- A report whose central finding is `C3` or worse states that in its limitations. No exceptions.
